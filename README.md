# Inventory-an-Billing-System

About the Project

A simple Inventory and Billing System developed using C++ and Object-Oriented Programming concepts.

Features

- Add new products.
- Display available products.
- Search products using Product ID.
- Generate customer bills.
- Check product stock availability.
- Automatically update inventory after billing.
- Save and load product information using file handling.

Concepts Used

- Classes and Objects
- Constructors
- Encapsulation
- Operator Overloading
- Vectors and Iterators
- File Handling
- Loops and Conditional Statements

Technologies

- Language: C++
- Concepts: Object-Oriented Programming
- Storage: File Handling

How to Run

1. Clone or download this repository.
2. Open "main.cpp" in a C++ compiler.
3. Compile and execute the program.
4. Follow the menu displayed on the screen.
